# Examples

`local-synthetic` is the supported schema-3 onboarding example. It contains only
generated numeric data and can run without inference, a GPU or network access.

`auto-cleanrl-report` and `auto-craftax-report` are **historical xgenius v1
scientific reports**. Their recorded methods, cluster references, figures and
conclusions are preserved, not ported into claims about the current runtime.
Their generator scripts are historical material, not supported runtime tools,
and neither those scripts nor the historical report bundles are published in
the v2 package.
