# Synthetic mean-shift research goal

Determine whether adding one to each of the fixed synthetic values `[2, 4, 6]`
increases their arithmetic mean by exactly one, while an unchanged replication
preserves the baseline mean.

Submit the three unchanged manifests in `batch.json` through xgenius once.
Do not run heavy work directly. Assess the registered baseline, replication
and shifted metrics, their numeric differences, execution and validation status.
Return an owned wait handoff while work remains, not an early completion.

The stopping criterion is explicit assessment of all three attempted conditions,
including any failure or invalid output, with a conclusion restricted to these
fixed values. Negative or incomplete evidence is acceptable; do not repeat a
failed condition automatically or invent a stronger generalization.

Do not change source, manifests, config or the goal; install packages; invoke
other providers/subagents; use a GPU, network, private datasets or remote compute;
create issues/PRs/commits; push or upload anything. Do not request report or
compaction inference. Use the supplied owned handoff, not an independent journal
checkpoint. Ask for no human collaboration to finish this bounded demonstration.
